Live medium

Requirements

  • The system requires an x86-64 machine that boots with UEFI, or QEMU with OVMF. Booting in legacy BIOS mode does not work.
  • The system requires a disk of 8 GB or more. The installer erases the disk.
  • The live system requires 3 GB of memory.

QEMU

$ truncate -s 20G disk.img
$ cp /usr/share/edk2/x64/OVMF_VARS.4m.fd vars.fd
$ qemu-system-x86_64 -enable-kvm -m 3072 -machine q35 \
    -drive if=pflash,format=raw,readonly=on,file=/usr/share/edk2/x64/OVMF_CODE.4m.fd \
    -drive if=pflash,format=raw,file=vars.fd \
    -drive file=disk.img,if=virtio,format=raw \
    -drive file=uranium-0.1.1.iso,media=cdrom -boot d \
    -nic user,model=virtio-net-pci

Live system

Log in as root with an empty password.

Run uranium-install, or follow the manual install.

The installer

The installer creates a GPT table with a 512 MB EFI System Partition and a btrfs filesystem with @ and @home, installs the system, takes the first frame and writes the boot menu.

The installer does not set up wireless, LVM, RAID or an encrypted root. For an encrypted root, use the manual install. uranium-install --config FILE reads the answers from a file of shell variables (DISK HOST USERNAME USERPASS ROOTPASS ZONE KEYMAP PROFILE EXTRA FIRMWARE), and -y skips the confirmation.
