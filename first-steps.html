First steps

Run setup to configure anything that the installer skipped.

Packages

The package index is not on the ISO, so you must fetch it once before the first install. rod +s pins the index to it's current revision:

# rod +s
# rod +f editor
# rod +i git tmux
# rod +i @tools

The sign @ names a package set, which is a file in /etc/rod/sets that has one package name per line.

Snapshots

rod takes a frame before every operation, autoframe takes one every hour, and every frame is a boot menu entry. To list the frames and to go back to one, run:

# scram roll
# scram flash --boot FRAME

Updating

rod +u builds the upgrade in a copy of the system and does not change the running system. The upgrade is applied at the next boot, where it runs on trial and is reverted if geiger fails:

# rod +u
# scram commit --boot
# reboot
