UraniumOS 0.1.0

2026-10-29

  • A live ISO with uranium-install, which installs onto btrfs and reads an answer file. The manual install can also create an encrypted root.
  • rod installs from a pinned Nix index, with generations, holds, package sets and recipes.
  • scram takes frames of the root and the home directories. It restores, flashes and bisects them, and applies updates that were tried in a copy at the next boot.
  • Every frame is a boot menu entry.
  • silo containers, hazmat sandboxes, blastdoor firewall ports and a geiger health report.
  • runit services, nftables dropping incoming traffic, and doas as the only setuid program.
