Download the free, public domain operating system, Uranium Operating System.

Download

"Release 0.1.0" refers to the version of UraniumOS for x86-64 PCs with UEFI that is offered on this page. It has been run only in QEMU. Before you try it on a real machine, read the known problems and the hardware status.

Install

Boot the ISO. The live system logs in as root with an empty password. Run uranium-install to install the system, or follow manual install to install it by hand.

The installer erases the disk you choose.

To write the ISO to a USB stick, run:

# dd if=uranium-0.1.0.iso of=/dev/sdX bs=4M status=progress oflag=sync

Check the download

To verify the files, place SHA256, SHA256.sig and the public key in one directory, and run:

$ signify -V -p uranium-0.1.pub -m SHA256 -x SHA256.sig
$ sha256sum -c --ignore-missing SHA256

The first command verifies the signature of the checksum list, and the second verifies the files. The key is also installed as /etc/signify/uranium-0.1.pub.
