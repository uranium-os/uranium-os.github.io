rod cheat sheet

Every operation of rod 0.1.0. NAME is a package, @SET a file in /etc/rod/sets. Details and error messages are in rod.

Packages

TaskCommand
Fetch the package indexrod +s
Pin the index to a nixpkgs commitrod +s REV (40 lowercase hex characters)
Show the pinrod +p
Installrod +i NAME...
Install a setrod +i @SET
Install a set without some membersrod +i @SET -i NAME...
Removerod +r NAME...
Remove a set but keep some membersrod +r @SET -r NAME...
Install againrod +r NAME +i NAME
Hold at the current versionrod +t NAME...
Release a holdrod -t NAME...
Upgrade everything not heldrod +u
Delete what nothing usesrod +c, and rod +c old with old generations

Look

TaskCommand
Searchrod +f WORD
Show a package of the indexrod +n NAME
List installedrod +l
List what you asked forrod +l explicit
Preview an upgraderod +h
Which package owns a filerod +w PATH
What a package needsrod +y NAME
What needs a packagerod -y NAME
Size of the profile or of packagesrod +z [NAME...]
List the files of a packagerod +q NAME
Why a package is installedrod +x NAME
Check installed filesrod +k

Try, share, preview

TaskCommand
Run without installingrod +e NAME -- COMMAND
Shell with a compilerrod +d NAME
Preview install, remove or upgraderod -n +i NAME, rod -n +r NAME, rod -n +u
Write the installed set to a filerod +o FILE
Install from such a filerod +a FILE

Go back

TaskCommand
List framesscram roll
Return to a framescram flash --boot FRAME, or a frame in the boot menu
Apply a pending updatescram commit --boot

-i and -r work only directly after +i and +r, and a name they take has to come from a package or set on the line. One line can hold several operations: rod +r htop +i htop.
